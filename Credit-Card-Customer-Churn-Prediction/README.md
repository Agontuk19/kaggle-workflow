# Credit Card Customer Churn Prediction
Churn classification on the **Bank Customer Churn dataset** using a simple **Artificial Neural Network (ANN)**.
### Workflow
- Dropped non-predictive columns
- Feature scaling and one-hot encoding
- ANN with 3 hidden layers (64-32-16)
- Early Stopping
- Threshold tuning for precision-recall tradeoff
### Result
**Accuracy: 86.4%**
### Tools
Python • Pandas • Scikit-learn • TensorFlow/Keras
